## 中文
- 按 F2 或点齿轮打开六分类配置面板；角色、地产、建造租金、商店道具、时间和高级数字可调。
- 草稿、应用并新开局、保存到本机相互独立；30 步撤销、25 个命名预设、JSON 导入导出。
- 本局沙盒：安全待机时修改两位玩家资源和地产归属/建筑，不保存战局。
- 0–20 倍目标速度（0.1 步进），0 暂停、20ms 单步；原版规则数字和默认 1 倍不变。
- 解压双击 Start-Game.cmd；受限时 Start-Local-Game.cmd，固定本机端口 18758。无需安装 Node、Java 或 Flash。
- 保存配置依赖当前浏览器与地址；换地址或设备请导出/导入 JSON。规则修改应用会新开选角，不是战局存档。

## English
- F2 / gear opens six configuration categories for characters, properties, construction/rent, items, timing and advanced source numbers.
- Separate draft, apply-and-restart and browser-save operations; 30-step draft undo, 25 named presets and JSON import/export.
- Session-only sandbox edits player resources and property ownership/buildings at safe idle points. It is not a saved game.
- Target speed 0–20x in 0.1 increments, 0x pause and original 20ms single-step; default 1x and original rule values are unchanged.
- Extract and open Start-Game.cmd; use Start-Local-Game.cmd if local-file loading is restricted (fixed loopback port 18758). No Node, Java or Flash installation.
- Browser saves are origin-specific. Export/import JSON to transfer configuration. Applying rules restarts at character selection.

See README, CUSTOMIZATION and STATUS for operation and verification boundaries.

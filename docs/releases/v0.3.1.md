# v0.3.1 · 编辑时继续运行 / Keep running while editing

## 中文

- 完全移除“编辑时暂停”。按 F2 打开、修改字段、关闭设置都不改变速度，移动、计时和正在进行的事件继续运行。
- 保留主动暂停与 0～20 倍控制。只有手动暂停/0 倍或页面隐藏保护会停止推进，关闭设置不会把手动 0 倍恢复为原速。
- 面板输入仍与游戏按键隔离。在面板打开时想掷骰或回应弹窗，点击画布再操作；关闭面板也会还原画布焦点。
- 即时调参、安全排队、显式保存和预设保持原来的区分。此更新针对不合理的自动暂停，不是 20 倍性能优化，也不代表修复了所有卡死或崩溃。

运行后按 **F2** 或点击齿轮即可边运行边修改；需要主动停下来时，使用暂停按钮或设为 **0 倍**。详见[修改指南](../CUSTOMIZATION.md)和[实际验收记录](../STATUS.md)。

## English

- Removed pause-while-editing entirely. Opening F2, editing and closing settings do not change speed: movement, timers and ongoing events keep running.
- Explicit pause and the 0–20× controls remain. Only manual pause/0× or hidden-page protection stops time; closing the editor never restores a user-selected 0× to normal speed.
- Editor typing remains isolated from game keys. Click the canvas to roll or answer a dialog with the panel open; closing the panel restores canvas focus too.
- Live application, safe queues, explicit saving and presets retain their separate roles. This removes an unwanted automatic pause; it is not a 20× performance optimization or a claim to fix all freezes/crashes.

Press **F2** or click the gear to edit while the game runs. Use pause or **0×** only when you want it stopped. See the [customization guide](../CUSTOMIZATION.md) and [actual verification status](../STATUS.md).

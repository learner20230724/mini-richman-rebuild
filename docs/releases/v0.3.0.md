# v0.3.0 · 本局即时调参 / Live customization

## 中文

- 设置不再默认要求重开：合法字段失焦或按 Enter 后自动应用本局，主按钮改为**立即应用本局**。手动重新开局保留为次级操作，并需确认。
- 角色只同步修改字段给使用该角色的玩家，不把整套初始值重新灌入所有玩家，也不清空位置和局面；后续选角使用更新后的初始配置。
- 地价、建造、租金、商店等规则影响后续操作。正在执行的交易会让整份更新等待安全时机，已付款和已收租金不追溯重算。
- 时间参数按进度调整；0～20 倍速度、暂停与 20 ms 单步继续保留。高级源码数字仍有风险与本局应用边界，不强制重放场景来“补应用”。
- 自动应用**不自动保存**。命名预设、JSON、本机已应用保存仍只保存规则，不是战局存档；本局沙盒继续作为独立的即时玩家/地产操作。
- 预设加载、JSON 导入、撤销与恢复属于批量草稿，需要明确点击“立即应用本局”；继续编辑小字段或关闭面板不会意外提交整份配置。

运行：解压后启动 `Start-Game.cmd`；本地文件受限时启动 `Start-Local-Game.cmd`。按 **F2** 或点击齿轮打开设置。完整语义见[修改指南](../CUSTOMIZATION.md)，实际验收范围见[交付状态](../STATUS.md)。

## English

- Valid field changes apply to the current match on blur/Enter by default. The primary action is now **立即应用本局 (apply now)**; restart is a separate, confirmed secondary action.
- Only edited character fields synchronize to players using that character. Other balances, positions and progress are not reset; later character selections use the updated starting configuration.
- Property, construction, rent and shop changes govern subsequent actions. Busy transactions queue the whole update until a safe point; paid costs and collected rent are not recalculated.
- Timing updates preserve interval progress. The 0–20× speed, pause and 20 ms single-step remain. Advanced source numbers retain risk and live-application limits; scenes are not forcibly replayed to reinitialize arbitrary state.
- Automatic application **does not automatically save**. Presets, JSON and explicit browser saving contain rules, not a match save. The current-player/property sandbox remains a distinct immediate tool.
- Loading presets, importing JSON, undo and resets create protected bulk drafts requiring an explicit apply; another small edit or closing the panel never accidentally submits the whole batch.

Run `Start-Game.cmd` after extraction, or `Start-Local-Game.cmd` if local files are restricted. Press **F2** or click the gear for settings. See the [customization guide](../CUSTOMIZATION.md) and [delivery status](../STATUS.md) for exact behavior and actual verification scope.
